# 6 Corners

A falling-hexagon puzzle game, first written for iOS in 2010–2011 and now rebuilt for the web as a PWA.

```sh
npm ci
npm run dev
```

- Game rules: [docs/rules.md](docs/rules.md)
- Contributor and agent notes: [AGENTS.md](AGENTS.md)
- The original iOS code: tag `v0-ios-legacy`
