# AGENTS.md

6 Corners is a falling-hexagon puzzle game, a rewrite of a 2011 iOS game. It
ships as a PWA for browsers, phones and desktops. The original code is on tag
`v0-ios-legacy` and branch `legacy/ios-cocos2d`, and is reference only: read its
rules and art, don't port its code.

## Commands

- Install: `npm ci` (Node version in `.node-version`; use fnm)
- Dev server: `npm run dev`
- All checks: `npm run check` (typecheck, lint, format check, tests)
- One test file: `npx vitest run src/core/game.test.ts`
- Format: `npm run format`
- Production build: `npm run build`

A task is done when `npm run check` and `npm run build` both pass.

## Layout

- `src/core/`: rules engine. Pure TypeScript, no DOM. Tests sit next to the code as `*.test.ts`.
- `src/art/`: the three skins (comic, digital, notebook) as SVG generators. Colours come from
  the 2011 sprites; keep them when changing shapes.
- `src/render/`: Canvas 2D board renderer. It rasterises the skin SVGs into tiles per size.
- `src/app.ts`: screen router and saved settings. `src/main.ts` is the entry.
- `src/ui/`: HTML screens (menus, game screen with HUD and pause/win/lose panels).
  Buttons are real `<button>`s; each skin restyles them in `src/style.css` via `data-skin`.
- `art.html` + `src/art-gallery.ts`: dev-only page comparing 2011 PNGs with the SVGs. Run
  `scripts/extract-legacy-art.sh` first; it fills the git-ignored `legacy-art/`.
- `public/art/splash.svg`: traced title screen, regenerated by `scripts/trace-splash.py`.
- `public/fonts/`: self-hosted OFL fonts. Keep each font's `-OFL.txt` next to it.
- `docs/rules.md`: game rules spec. Read it before changing anything in `src/core`.
- `public/`: static assets and PWA icons.

## Rules engine

- `src/core` is pure and deterministic: no DOM, timers, `Math.random` or `Date.now`.
  Time enters only through `tick(state, dtMs)`, randomness only through the seeded RNG
  in `rng.ts`. ESLint enforces this.
- State is immutable: `act` and `tick` return a new `GameState` and a list of events.
  The UI reacts to events (spawn, lock, lines, won, lost) and doesn't diff state.
- Cells use doubled-height hex coordinates (see `docs/rules.md`). Don't use pixel
  positions for game logic.
- A rule change updates `docs/rules.md`, including "Changes from 2011", in the same change.
- Add a test for each rule change or bug fix.

## Code style

- TypeScript strict mode with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`.
  No `any`, no non-null `!`.
- Prettier (single quotes, width 100) and typescript-eslint `strictTypeChecked`.
- Comments explain why, not what.

## Dependencies

- Versions are pinned exactly in `package.json`. Ask before adding a dependency.
- TypeScript stays on 6.0.x until typescript-eslint supports 7.
- Before using a library API, look up its current docs. Vite 8 and Vitest 5 differ
  from older examples.

## Git

- `master` is the main branch. Work on a feature branch.
- Commit messages: imperative, under 72 characters.
